# AI-Generated Binaries

A collection of experimental AI-generated binaries created by **Rooke Poole** using the [PARS workflow](https://github.com/rookepoole/PARS).

These projects explore what AI can produce when executable artifacts are the medium. Evidence and documentation vary by experiment; consult the available records before drawing conclusions about runtime behavior or how an artifact was generated.

Questions, reproduction attempts, and constructive criticism are welcome. If you find a problem or a gap in the evidence, please open an issue with the artifact name, what you observed, and any steps needed to reproduce it.

Software is provided **as is**. Inspect unfamiliar executable files and use an isolated test environment before running them.
